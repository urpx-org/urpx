# Code of Conduct

The URPX project follows the [LF Projects Code of Conduct](https://lfprojects.org/policies/code-of-conduct/), which applies to all project spaces: the repositories, issue trackers, mailing list, and working group meetings.

In short: be kind, be constructive, assume good faith.

## Reporting

To report a violation, contact the Linux Foundation via the process described in the [LF Projects Code of Conduct](https://lfprojects.org/policies/code-of-conduct/) (manager@lfprojects.org).

For non-confidential community matters, use the working group mailing list: urpx-wg@lists.lfenergy.org.
